## 证据原则

- 第三方面试材料用于发现问题和组织课程，不自动视为正确答案。
- `planned`、`draft`、`to-verify`、`verified` 继续表示证据等级。
- 项目实现题优先回到 submodule 源码；协议、论文和平台能力优先回到官方来源。
- 面试答案可以先形成通俗可复述版本，但技术结论未核验时必须保留状态标记。
